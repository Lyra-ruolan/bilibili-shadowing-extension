开始练习

  1. 在 Chrome 中安装扩展后，打开一个有可读取英文 CC 字幕的普通哔哩哔哩 BV 视频。刚安装时请刷新已打开的视频标签页。
  2. 点击扩展图标打开侧栏，等待字幕载入；需要时展开视频信息选择字幕轨道。
  3. 展开「练习设置」，选择整句或分段、播放模式与速度，点击播放开始跟读。
  4. 需要复习材料时，在顶部视频信息中选择字幕内容与格式，然后下载。

在练习区域可使用 J、空格、L 控制上一项、播放/暂停与下一项；扩展快捷键默认 Alt+Shift+J / K / L。

适用范围

需要 Chrome 114 或更高版本、可访问哔哩哔哩的网络，以及当前分P可读取的英文 CC 字幕。部分字幕需要先登录哔哩哔哩。

支持普通 BV 视频。番剧、直播、课程、互动视频、短链接、只有画面内硬字幕的视频不在支持范围内。本扩展不生成字幕，也不提供录音、语音识别、发音评分、自动翻译或视频下载。

数据与联系

字幕处理和导出在本地完成。扩展会访问哔哩哔哩接口获取视频及字幕信息，并保存练习偏好和最多 50 条轨道选择；没有广告、遥测或开发者后台。详见完整中英文隐私政策。

普通报错、建议及隐私问题，请通过 GitHub Issues 联系维护者。Issues 是公开渠道，提交需要 GitHub 账号；请勿附上密码、Cookie、令牌、个人敏感信息或私人字幕。

Listen closely. Speak along.

Shadowing Studio is an independent, unofficial English shadowing extension for regular Bilibili BV videos with accessible English CC subtitles. The interface is in Simplified Chinese.

Practise whole sentences or shorter segments, use single-unit playback, continuous playback or looping, and choose speeds from 0.5× to 2×. Export processed sentences or original cues locally as SRT, TXT, Markdown or JSON.

Getting started

  1. Install the extension in Chrome 114 or later, then refresh a supported video page with existing English CC. Some subtitles require signing in to Bilibili.
  2. Click the extension icon to open the side panel and wait for subtitles.
  3. Open 练习设置 (Practice settings), choose 整句 (Sentence) or 分段 (Segment), select a mode and speed, then play.
  4. Expand the video information area to choose a subtitle track or export format.

Burned-in captions, videos without accessible English CC, bangumi, livestreams, courses, interactive videos and short URLs are outside the supported scope. The extension does not generate subtitles, recognize speech, record audio, score pronunciation, translate content or download video.
